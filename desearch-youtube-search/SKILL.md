# YouTube Search By Desearch

Real-time public YouTube data: keyword search, video details, transcripts (captions), top-level comments, channel metadata, and a channel's uploads. Public data only; no video downloads.

## Setup

1. Get an API key from https://console.desearch.ai
2. Set environment variable: `export DESEARCH_API_KEY='your-key-here'`

## Pricing

Every command is one request, billed at $2.07 per 1,000 requests, including a page with no results. A `404` (for example a video without captions) and a `422` are not charged.

## Pagination

`youtube_search`, `youtube_comments`, and `youtube_channel_videos` return one page:

```json
{
  "results": [ ... ],
  "next_cursor": "eyJ2IjoxLCJyb3V0ZSI6..."
}
```

For the next page, run the same command with the same target (query and filters, video, or channel) plus `--cursor <next_cursor>`. `next_cursor` is `null` on the last page; stop there.

```bash
scripts/desearch.py youtube_channel_videos @MrBeast
scripts/desearch.py youtube_channel_videos @MrBeast --cursor "eyJ2IjoxLCJyb3V0ZSI6..."
```

- The cursor is opaque. Send it back exactly as printed; never build or edit one.
- A cursor works only for the command and target that returned it, for 24 hours. Any other value returns `422` and is not charged.
- Each request reads one YouTube page, so page sizes vary.

## IDs and URLs

Commands that take a video ID also take its full URL (`https://www.youtube.com/watch?v=…`, `https://youtu.be/…`, or a Shorts URL). Channel commands take a handle with or without `@`, or a channel ID (`UC…`).

## Common Fields

### Search item (`youtube_search`, `youtube_channel_videos`)
| Field | Type | Description |
|-------|------|-------------|
| `id` | string\|null | Video, channel, or playlist ID |
| `type` | string\|null | `video`, `short`, `live`, `channel`, or `playlist` |
| `url` | string\|null | YouTube URL (channel and playlist search items can have none) |
| `title`, `description`, `thumbnail` | string\|null | Title, snippet, and thumbnail |
| `channel` | Channel ref\|null | `{id, title, handle, url, thumbnail, subscriberCountText}` |
| `views`, `likes`, `comments` | int\|null | Counts, when shown |
| `publishedAt` | string\|null | Best-effort ISO time derived from `publishedText` ("9 days ago") |
| `durationSeconds`, `durationText` | int\|string\|null | Length |
| `handle`, `subscriberCountText`, `videoCountText` | string\|null | Channel results only |
| `videoCount` | int\|null | Playlist results only |

### Video (`youtube_video`)
Search item fields plus `genre`, `keywords` (string[]), `chapters` (`{title, startSeconds, startText}`[]), `captionLanguages` (`{languageCode, name, autoGenerated}`[], the tracks `youtube_transcript` can read), `isPaidPromotion`, and `isMadeWithAI`. `publishedAt` is exact here.

Fields a result does not report can be missing or `null`; treat them as unknown, not zero.

## Commands

### `youtube_search`: Search YouTube

```bash
scripts/desearch.py youtube_search "bittensor"
scripts/desearch.py youtube_search "bittensor" --type videos --upload-date this_month --sort-by popular
```

**Options:**
| Option | Description |
|--------|-------------|
| `--type` | `videos`, `shorts`, `channels`, or `playlists`. Omit for mixed results. |
| `--upload-date` | `today`, `this_week`, `this_month`, or `this_year` |
| `--sort-by` | `relevance` or `popular` |
| `--duration` | `under_3_min`, `between_3_and_20_min`, or `over_20_min`. Applies to videos, not Shorts. |
| `--cursor` | `next_cursor` from the previous page. Works only with the same query and filters. |

Use `intitle:"…"` in the query for stricter title matching.

**Response:** `{ results: SearchItem[], next_cursor }`


### `youtube_video`: Retrieve Video

```bash
scripts/desearch.py youtube_video dQw4w9WgXcQ
scripts/desearch.py youtube_video "https://youtu.be/dQw4w9WgXcQ"
```

**Response:** `Video`


### `youtube_transcript`: Retrieve Transcript

```bash
scripts/desearch.py youtube_transcript dQw4w9WgXcQ --language en
```

**Options:**
| Option | Description |
|--------|-------------|
| `--language` | Caption language code such as `en`, `es`, or `pt-BR`. Omit for YouTube's default track. |

**Response:** `{ videoId, type, url, language, text, segments }`. `text` is the whole transcript; each segment is `{ text, startMs, endMs, startText }`. A video without captions returns `404` and is not charged.


### `youtube_comments`: Video Comments

Top-level comments only.

```bash
scripts/desearch.py youtube_comments dQw4w9WgXcQ --order newest
```

**Options:** `--order` (`top` or `newest`) and `--cursor`.

**Response:** `{ results: Comment[], next_cursor }`. A comment is `{ id, videoId, text, publishedAt, publishedText, author: {name, channelId, url, avatar, verified, isCreator}, likes, replyCount }`.


### `youtube_channel`: Retrieve Channel

```bash
scripts/desearch.py youtube_channel @MrBeast
```

**Response:** `{ id, url, handle, name, description, avatar, subscribers, subscriberCountText, videoCountText, viewCountText, joinedText, country, tags, links, email, twitter, instagram }`. `email` is set only when the channel lists a public one.


### `youtube_channel_videos`: Channel Videos

```bash
scripts/desearch.py youtube_channel_videos @MrBeast --sort popular
```

**Options:** `--sort` (`latest`, the default, or `popular`) and `--cursor`.

**Response:** `{ results: SearchItem[], next_cursor }`

### Errors
| Status | Meaning |
|--------|---------|
| 401 | Missing or invalid API key |
| 402 | Balance depleted |
| 404 | Video, transcript, or channel not found (not charged) |
| 422 | Invalid parameters, or a cursor that is expired or came from another command or target (not charged) |
| 429 | Too many requests |

Error bodies are JSON with a `detail` field and are printed as returned.
